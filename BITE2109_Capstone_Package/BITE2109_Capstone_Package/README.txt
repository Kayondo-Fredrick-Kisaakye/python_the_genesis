BITE 2109 CAPSTONE PACKAGE — READ ME FIRST
============================================

Four things are in this folder:

1. Offline_Setup_Guide.pdf
   -> Start here. One-time setup checklist, what needs internet vs.
      what doesn't, and what each Python package is for.

2. Supplementary_Study_Guide.pdf
   -> Topics beyond Python Crash Course (exceptions in depth, requests,
      BeautifulSoup, decorators, map/filter/reduce, threading, asyncio,
      pytest/mocking, cProfile). Each section says which PCC chapter to
      finish first before reading it. Not for reading cover-to-cover —
      grow into it as you go through the book.

3. Multi_Threaded_Data_Aggregator_Solution.pdf
   -> The full, tested, working solution to the actual capstone
      assignment, with heavy explanations. This is the advanced one —
      most of it is well beyond dictionaries, and that's expected.

4. source_code/
   -> The actual runnable .py files from the solution above:
      config.py, mock_server.py, api_fetcher.py, scraper.py,
      data_models.py, analyzer.py, reporter.py, main.py,
      test_project.py

SUGGESTED ORDER
---------------
1. Read Offline_Setup_Guide.pdf and do the one-time setup.
2. Keep working through Python Crash Course as normal.
3. After each relevant PCC chapter, read the matching section of
   Supplementary_Study_Guide.pdf (see its table in Section 11).
4. Once you're comfortable with most of the study guide, open
   Multi_Threaded_Data_Aggregator_Solution.pdf and work through
   source_code/ file by file, running each part yourself.

No internet needed for any of this once it's downloaded and
Python's packages are installed — see the Offline Setup Guide.
